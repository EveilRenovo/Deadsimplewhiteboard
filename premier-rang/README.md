# Premier Rang — site vitrine

Site statique (HTML/CSS/JS, sans dépendance) pour Premier Rang, soutien scolaire
des collégiens et lycéens des établissements français de Casablanca et Rabat.

- `index.html` — contenu de la page
- `styles.css` — charte (bleu nuit `#0F2147`, rose `#E8365D`, blanc)
- `script.js` — menu mobile, onglets Collège/Lycée, formulaire de contact
- `assets/` — emblème vectoriel (plume) et logo original

Ouvrir `index.html` dans un navigateur suffit. Pour la mise en ligne, déposer le
dossier sur n'importe quel hébergeur statique (Netlify, GitHub Pages, OVH…).

**À compléter :** l'adresse e-mail de réception dans `script.js` (`CONTACT_EMAIL`),
et éventuellement téléphone / adresses des locaux / tarifs.
